# Currículo — Keverson Souza

Currículo online responsivo feito com **Vue 3**, **Vite** e **Tailwind CSS**.

## Requisitos

- [Node.js](https://nodejs.org/) 20 ou superior (desenvolvido com a versão 23.9)

## Rodando localmente

```bash
# Instalar as dependências (apenas na primeira vez)
npm install

# Iniciar o servidor de desenvolvimento
npm run dev
```

Acesse o endereço exibido no terminal (normalmente `http://localhost:5173`).

## Gerando a versão final

```bash
npm run build
```

Os arquivos são gerados na pasta `dist/`. Para visualizá-los localmente:

```bash
npm run preview
```
